# POPコンテスト

ポップコンテストの投票サイトです。

## サイトの内容

- No.1〜15の作品写真。No.6は2枚の写真を切り替えて表示
- スマートフォンでも4列表示、作品を押すと拡大
- 投票は1人1票のお願いを表示
- 投票結果はページ下部のリンクから確認
- 作成：一宮高等学校 図書委員会・塚田

## 投票の集計

投票数はGoogle Apps ScriptのScript Propertiesに15作品分の件数として共有保存します。スプレッドシートは使いません。

- ウェブアプリAPI: `config.js` に設定済み
- Apps Scriptプロジェクト: https://script.google.com/home/projects/1Yn8g4OPZ8lH6DM35ZyvFIYlxGKsxEBtHHyYFEw2XtD4yeSPyStpJwXsQ/edit
- バックエンドのソース: `backend/Code.gs`

結果確認を有効にするには、Apps Scriptの `RESULTS_PASSWORD` を関係者用パスワードに設定して保存し、「デプロイを管理」から新バージョンを公開してください。公開範囲は「全員」です。パスワードはこのリポジトリやサイトのファイルに保存しないでください。

「一人一票」は運用上のお願いです。同じブラウザーでは再投票を抑止しますが、ログイン認証は行わないため、別のブラウザーや端末からの重複投票は防げません。

## GitHub Pages

このフォルダーのファイル一式をリポジトリのルートへ置き、GitHub Pagesで公開します。独自ドメインを使う場合は、別途ドメイン登録とDNS設定が必要です。
